# User Preferences

## Communication Style
- Be concise and direct
- No emojis unless explicitly requested
- Skip unnecessary preamble and summaries
- When uncertain, ask rather than assume

## Code Style
- Prefer explicit over implicit
- Write self-documenting code; avoid excessive comments
- Keep functions small and focused
- Handle errors explicitly, don't swallow them

## Workflow
- Show diffs before making changes to critical files
- Run tests after code changes when test suite exists
- Prefer editing existing files over creating new ones
- Use conventional commit messages

## Don't
- Add features beyond what was requested
- Create documentation files unless asked
- Add logging/debugging code unless debugging
